# Cybersecurity Threat Report — Task-1 (Maincrafts Internship)

## Overview
This repository contains my Task-1 submission for the Cybersecurity Analyst Internship at **Maincrafts** — a threat intelligence report covering five major modern cyber threats, their real-world impact, and defensive strategies.

## Threats Covered
1. AI-Powered Phishing Attacks
2. Ransomware-as-a-Service (RaaS)
3. Cloud Security Misconfigurations
4. IoT Vulnerabilities
5. Zero-Day Exploits

Each threat is broken down into: how the attack works, why it's dangerous, impact on individuals and organizations, a real-world case study, and preventive measures.

## Case Studies Referenced
- Arup deepfake video call fraud (2024)
- Colonial Pipeline ransomware attack (2021)
- Capital One cloud breach (2019)
- Mirai botnet / Dyn DDoS attack (2016)
- Log4Shell / Log4j vulnerability (2021)

## Sources
Research drawn from CISA, NIST, OWASP, the U.S. Department of Energy, KrebsOnSecurity, and CNN. Full citations are listed in the report's References section.
